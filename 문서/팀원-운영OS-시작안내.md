# 큐앤뱅 뉴 대시보드 시작 안내

## 기준 공간

모든 팀원은 구글 드라이브 데스크톱에서 `내 드라이브/큐앤뱅 뉴 대시보드`를 같은 위치로 동기화한다. 프로젝트 파일·운영원장·회의록·공용도구는 이 폴더를 기준으로 확인한다.

## 매일 쓰는 위치

- 오늘 해야 할 일, 받은 내용, 일정, 고객·명함, 프로젝트 현황: 새 운영 대시보드
- 고객 제공 자료·기획·디자인·영상 편집 원본·최종 전달 파일: 해당 프로젝트 폴더
- 회사 공통 규칙: `00_회사규칙`
- 개인 AI 작업 규칙과 개인 메모: `08_개인작업공간/이름/01_개인작업규칙`
- 재사용 가능한 실제 도구: `07_공용도구`

## 새 프로젝트 시작

1. 고객·마감·만들 결과가 정해진 일은 `01_프로젝트`에서 다음 번호를 받아 만든다.
2. 프로젝트 운영원장에는 개요·진행·할일·결정·일정·이력·링크를 기록한다.
3. 파일은 `01_자료`, `02_제작`, `03_결과물` 안에만 둔다.
4. 확정 견적·계약·정산 원본은 `05_행정`에 두고 프로젝트 원장에는 링크만 둔다.

## 각 컴퓨터의 역할

- 구글 드라이브: 실제 업무 파일의 공용 원본
- 새 운영 대시보드: 원장을 읽어 오늘 할 일과 프로젝트 진행을 보여주는 화면
- GitHub: 배포되는 앱 코드만 관리. 프로젝트 자료를 GitHub에 올리지 않는다.
- 개인 규칙: 회사 규칙을 복사하지 않고, 각자의 작업 방식·AI 설정만 적는다.

## 주의

- 같은 파일을 두 컴퓨터에서 동시에 편집하지 않는다. 구글 문서·구글 시트는 공동 편집하고, 영상·디자인 원본은 편집 전 담당자를 정한다.
- 카카오톡·라크·메일에서 받은 원문은 통합 수신함에 남긴다. 요약본만 남기고 원문을 버리지 않는다.
- 실행 코드, 비밀키, 로그인 정보, 빌드 캐시는 드라이브에 넣지 않는다.
