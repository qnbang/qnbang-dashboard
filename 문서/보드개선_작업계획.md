## 1. ✅ 노션식 공유 토글 — 완료 (2026-06-16)

**구현됨·라이브.** 문서 모달의 🔗 공유 버튼으로 켜고 끄면 공개 링크가 살고 죽음. 공개 상태는 대시보드 repo `share-registry.json`에 slug 단위 기록(`lib/share.ts`, GITHUB_TOKEN 재사용, 배포 없이 즉시 반영) → 동적 라우트 `app/share/[slug]/page.tsx`가 확인 후 GitHub서 MD fetch·렌더(없으면 404). 토글 API = `app/api/share/route.ts`. 렌더 로직은 변환기에서 `lib/md.ts`로 포팅. (계획의 구글시트 대신 셋업 0인 GitHub 파일 사용 — 현 시트가 읽기전용이라.) 상세는 `0_작업로그.md` 2026-06-16 참조.

### 1. ⭐ 노션식 공유 토글 (핵심 / 약 2~3h / 무료)

**목표:** 대시보드에서 문서를 열고 **"🔗 공유" 버튼**을 누르면 공개 링크가 살아나고, 끄면 죽는다. 노션 "웹에 게시"와 동일 UX.

**구현 방향 (시스템지도 설계 그대로):**
- 공개 여부를 **구글시트에 slug 단위로 기록** (`lib/sheet.ts` 패턴 재사용). 토글 = 시트에 추가/제거 → **배포 없이 즉시 반영.**
- **`/share/[slug]` 동적 라우트**(`app/share/[slug]/page.tsx`)가 요청 시: ①시트에서 공개 여부 확인 → ②공개면 해당 MD를 GitHub API로 fetch → ③렌더(변환기 로직을 Next로 포팅 or marked 사용) → ④비공개면 404.
- 현재 정적 파일(`public/share/*.html`) 방식 → 동적 라우트로 전환(또는 병행).

**이미 있는 재료:** `/share` 경로 인증 제외 완료 · MD 렌더 로직(`.tools/md-읽기페이지/변환.mjs`) · 구글시트 백엔드 · `GITHUB_TOKEN`(repo 문서 fetch).

**주의:** middleware는 이미 `share` 열림(추가 작업 불필요). slug는 추측 어렵게(노출 = 링크 아는 사람 누구나). 자동만료·비번 옵션은 추후.

## 2. ✅ 대시보드 문서 편집 — 완료 (2026-06-16)

**구현됨·라이브.** 문서 모달의 ✏️ 편집 → textarea로 원문 수정 → 저장하면 GitHub Contents API PUT으로 커밋(폰·외부에서도). **sha 기반 충돌 방지**: 불러올 때 받은 sha를 저장 때 되돌려줌 → 그 사이 바뀌었으면 409로 거절, 덮어쓰지 않고 경고만. 코드: `lib/github.ts`(`getDocFull`·`saveDoc`) + `app/api/git-projects/[repo]/doc`(GET+PUT) + 모달 편집 UI. **역할분담**: 옵시디언=정밀편집(원본), 대시보드=급할 때 빠른 수정 → 로컬서 이어 작업하려면 먼저 `git pull`(저장 후 화면 안내). 상세 `0_작업로그.md` 2026-06-16.

<details><summary>원래 계획(참고용)</summary>

**목표:** 대시보드에서 MD를 직접 고쳐 GitHub에 저장. **폰·외부에서도 편집**(옵시디언은 맥 전용).

**구현 방향:** GitHub Contents API `PUT`으로 파일 commit. **sha 기반 충돌 방지** 필수.

**주의 (중요):** 지금 철학은 "**로컬 MD가 원본**(옵시디언·클로드 편집)". 대시보드 편집을 더하면 편집 경로가 둘 → 동시 수정 시 충돌. "원본은 하나" 원칙 정리 필요. **풀 에디터보다 인라인 간단편집(제목·메모·짧은 수정)부터.** 역할분담: 옵시디언=정밀편집 / 대시보드=보고+공유+급할 때 수정.

</details>
