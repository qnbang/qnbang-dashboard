# 지영씨 — 프로젝트가 대시보드에 자동으로 뜨는 방식이 바뀌었어요 (2026-07-02)

## 한 줄 요약
**깃허브에 푸시만 하면 끝.** 다음 날 아침(6:30) 대시보드 보드에 카드가 자동으로 생깁니다.
따로 등록하거나 요청할 것 없음. (예전 "진행 중 프로젝트 (깃 자동)" 파란 섹션은 없어졌어요 — 전부 위 보드로 통일)

## 자동 등록이 되려면 저장소에 2가지만 있으면 됩니다
지영씨 컴퓨터의 클로드가 새 프로젝트 만들 때 보통 자동으로 해주는 것들이라, 확인만 하면 됩니다.

1. **저장소 토픽**: `qnbang-project` 토픽이 붙어 있어야 감지됩니다.
   - 확인/추가: 깃허브 저장소 페이지 → About(오른쪽 위) → ⚙️ → Topics에 `qnbang-project`
2. **`프로젝트.json`** (저장소 최상위): 카드에 표시될 정보의 원본입니다.
   ```json
   {
     "이름": "아트 디렉터 에이전트",
     "담당자": "김지영",
     "진행상태": "진행 중",
     "분류": "자체"
   }
   ```
   - `이름` = 카드에 뜨는 프로젝트명 (파란 글씨)
   - `분류` = 고객 일이면 `"대행"`(고객사 뱃지가 붙음), 우리 것이면 `"자체"`
   - `마감일`("YYYY-MM-DD")을 넣으면 D-day 뱃지가 뜹니다

## 프로젝트가 끝났을 때
둘 중 아무거나 하면 됩니다. 어느 쪽이든 보드·깃에서 같이 정리됩니다.
- **대시보드에서**: 카드 열고 완수 처리 (평소처럼)
- **깃에서**: `프로젝트.json`의 `"진행상태"`를 `"완료"`로 바꿔 푸시

※ 대시보드에서 완수 처리하면, 깃 쪽 상태가 "진행 중"으로 남아 있어도
   다음 날 아침 시스템이 알아서 깃 쪽도 "완료"로 정리합니다(자동 커밋 1개 생김 — 정상).

## 이름을 나중에 바꾸고 싶으면
카드와 깃은 이름이 아니라 **저장소 이름(열쇠)** 으로 연결돼 있어서,
`프로젝트.json`의 `이름`이나 시트의 프로젝트명을 바꿔도 연결이 안 끊깁니다. 자유롭게 바꾸세요.
