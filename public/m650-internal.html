M650 — 내부 할 일 (클로드 / 대표 구분)

공유본에선 전부 '큐앤뱅'으로 보이지만, 실제로 클로드(자동 처리)와 대표(직접 해야 할 일)를 나눈 버전. 내가 뭘 챙겨야 하는지 여기서 확인.

역할 한눈에

클로드바로 할 수 있는 것 (글·구조 = 얼라인 본체)

  • 게임형 챕터 스토리보드 → 각 장소 페이지 문구까지 전개
  • 코멘트 텍스트 수정 전부 (뿌리관 정리·퍼레이드 재서술·던전 느낌 등)
  • 페이지·프로그램 스토리 순서 재배치안 작성
  • 오류·잔재 정리 (GKL·경기도·진행자·날짜/3일↔4일)
  • 일정표·세부설명 톤앤매너 통일
  • 개막식 아티스트 퍼포먼스 방향·문구, 갓챠·플리마켓 운영규칙 글
  • (원하면) PPT 텍스트 실제 수정 — `.tools/ppt읽기.py`

대표직접 해야 하는 것 (결정·외부확인·자료)

  • 씨투아 컨펌 — 스토리 흐름 틀 + 선결 3사항(M650 시작/끝·감정순서·곁가지)
  • 발주처 확인 — 확정 행사일(10/7~10 中 4일)
  • 부장님 의도 — 플리마켓 운영 방향
  • 실행 결정 — 여름 워터밤 사전이벤트 / 위령제 주민 공동 여부
  • 섭외·자료 — 실제 아티스트팀·진행자, 갓챠 상품·이미지·선물 사진
